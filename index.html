Sistem Informasi Pengarsipan Dokumen Analisis Gender.

Platform resmi pengumpulan dan manajemen dokumen GAP, GBS, KAK, dan SK Tim bagi seluruh Organisasi Perangkat Daerah (OPD) di lingkup Pemerintah Provinsi Nusa Tenggara Timur.

Mulai Unggah Berkas Selanjutnya

Proses Lebih Mudah

Sistem ini mengubah cara pengumpulan dokumen dari manual menjadi digital, sehingga lebih praktis, aman, dan langsung tersimpan.

1. Kirim Sekaligus

Unggah 4 dokumen wajib PUG langsung dalam satu form secara elektronik.

2. Format Otomatis

Sistem akan merapikan dan mengubah nama file Anda secara otomatis agar seragam.

3. Langsung Tersimpan

Dokumen yang Anda kirim akan langsung masuk dan tercatat di pusat data Dinas.

Pastikan 4 berkas di bawah ini telah disiapkan dalam format (PDF/Word/Excel) sebelum Anda mulai mengisi formulir pengumpulan.

Gender Analysis Pathway. Berkas analisis alur kesenjangan OPD.

Gender Budget Statement. Pernyataan alokasi anggaran responsif gender.

3. Dokumen KAK

Pusat Bantuan & FAQ

Seputar Pengarsipan SIPMODAG
Kapan batas akhir pengumpulan dokumen ini?

Batas waktu pengumpulan berkas mengikuti surat edaran resmi dari Kepala Dinas P3AP2KB Provinsi NTT yang dikirimkan ke masing-masing OPD.

Mengapa formulir di website belum bisa diisi?

Fitur unggah mandiri langsung via website saat ini masih dalam tahap finalisasi keamanan server. Harap gunakan tombol Google Form sementara di atas.

Bagaimana jika ukuran file saya lebih dari 10 MB?

Anda disarankan untuk melakukan kompresi PDF terlebih dahulu melalui kompresor online gratis terpercaya sebelum mengunggahnya.

Apakah format nama file harus diatur manual?

Tidak perlu. Saat fitur web dibuka, sistem akan otomatis mengubah nama file sesuai dengan nama OPD dan tahun dokumen yang Anda pilih.

Butuh bantuan teknis lain? Hubungi Tim Admin Dinas P3AP2KB.
