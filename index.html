Sistem Informasi Pengarsipan Dokumen Analisis Gender.

Platform resmi pengumpulan dan manajemen dokumen GAP, GBS, KAK, dan SK Tim bagi seluruh Organisasi Perangkat Daerah (OPD) di lingkup Pemerintah Provinsi Nusa Tenggara Timur.

Mulai Unggah Berkas Selengkapnya

Proses Lebih Mudah

Sistem ini mengubah cara pengumpulan dokumen dari manual menjadi digital, sehingga lebih praktis, aman, dan langsung tersimpan.

1. Kirim Sesuka Hati

OPD dapat mengirim dokumen yang sudah siap terlebih dahulu. Tidak wajib mengunggah keempatnya sekaligus.

2. Format Otomatis

Sistem akan merapikan dan mengubah nama file Anda secara otomatis agar seragam di pangkalan data.

3. Pemantauan Live

Data dokumen yang dikirim akan langsung tercatat dan diperbarui pada tabel statistik website.

Statistik Pengumpulan Dokumen

Data pemantauan langsung kepatuhan penyampaian dokumen Pengarusutamaan Gender (PUG) oleh seluruh OPD Provinsi NTT tahun anggaran berjalan.

Persyaratan Berkas

Anda tidak harus mengunggah semua dokumen sekaligus. Silakan unggah dokumen yang sudah siap terlebih dahulu (Format PDF/Word/Excel).

1. Dokumen GAP

Gender Analysis Pathway. Berkas analisis alur kesenjangan OPD.

2. Dokumen GBS

Gender Budget Statement. Pernyataan alokasi anggaran responsif gender.

3. Dokumen KAK

Kerangka Acuan Kegiatan atau Term of Reference (ToR).

4. SK Tim Focal Point

Surat Keputusan Tim Pengarusutamaan Gender di lingkup Instansi.

Pusat Bantuan & FAQ

Seputar Pengarsipan SIPMODAG
Kapan batas akhir pengumpulan dokumen ini?

Batas waktu pengumpulan berkas mengikuti surat edaran resmi dari Kepala Dinas P3AP2KB Provinsi NTT yang dikirimkan ke masing-masing OPD.

Apakah sistem pengunggahan ini aman?

Sangat aman. Setiap berkas terenkripsi langsung secara otomatis di server pangkalan data instansi sehingga data PUG OPD tidak akan bocor.

Bagaimana jika ukuran file saya lebih dari 10 MB?

Anda disarankan untuk melakukan kompresi PDF terlebih dahulu melalui kompresor online gratis terpercaya sebelum mengunggahnya.

Apakah format nama file harus diatur manual?

Tidak perlu. Saat tombol kirim ditekan, sistem secara otomatis merapikan penamaan berkas berdasarkan jenis dokumen, nama instansi, dan tahun anggaran.

Butuh bantuan teknis lain? Hubungi Tim Admin Dinas P3AP2KB.
