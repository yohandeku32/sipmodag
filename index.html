Mulai Upload

Mengapa SIPMODAG Dibuat?

Kami memahami birokrasi pengarsipan seringkali memakan waktu. Kami mengubah proses manual menjadi sepenuhnya otomatis.

Cara Lama

  • • Kirim file via WhatsApp atau Email
  • • Nama file tidak seragam / berantakan
  • • Admin P3AP2KB harus mengunduh satu-satu
  • • Sulit melacak OPD mana yang belum setor
Solusi!

Dengan SIPMODAG

  • • Unggah mandiri langsung dari website
  • • File otomatis di-rename sesuai standar
  • • Folder dibuat otomatis di Google Drive
  • • Dashboard Real-Time di Google Sheets

Cara Sistem Bekerja

1. Isi Form

Pilih nama instansi Anda dari dropdown, lalu unggah dokumen yang diminta via form tanpa perlu proses login tambahan.

2. Auto-Routing

Secara magis, API kami akan mengganti nama file Anda dan memindahkannya ke folder khusus instansi Anda di Google Drive.

3. Sinkronisasi Data

Setiap entri yang berhasil akan langsung memperbarui status pelaporan di Dashboard Google Sheets pusat P3AP2KB.

Portal Pengiriman Arsip

Pilih instansi Anda, jenis dokumen, dan lampirkan file (Maks. 10MB).

Kategori
Dokumen.

GAP

Gender Analysis Pathway. Panduan alur analisis kesenjangan.

GBS

Gender Budget Statement. Dokumen pernyataan alokasi anggaran.

KAK

Kerangka Acuan Kegiatan yang responsif gender.

SK Tim

SK Tim Focal Point Pengarusutamaan Gender di OPD.
