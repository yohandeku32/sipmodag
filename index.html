Unggah dokumen gender OPD dengan alur yang lebih rapi.

Landing page ini menjadi pintu masuk menuju Google Form pengumpulan dokumen GAP, GBS, KAK, dan SK Tim Focal Point. Halaman dibuat sederhana agar mudah diakses, cepat dimuat, dan siap dipublikasikan melalui GitHub Pages.

Dokumen yang dihimpun

Setiap OPD diarahkan untuk mengunggah dokumen wajib melalui satu formulir yang sama agar data masuk seragam dan mudah dimonitor.

GAP
Dokumen analisis gender program atau kegiatan.
GBS
Dokumen anggaran responsif gender.
KAK
Kerangka acuan kegiatan pendukung.
SK Tim Focal Point
Dokumen penetapan tim atau focal point.

Apa fungsi halaman ini?

Halaman ini tidak menggantikan formulir, tetapi menjadi wajah depan yang lebih resmi untuk SIGMA Gender. Pengguna membaca informasi singkat terlebih dahulu, lalu diarahkan ke Google Form untuk proses unggah dokumen.

Akses lebih jelas

OPD tidak langsung menerima link form mentah, tetapi masuk dari halaman yang memiliki nama sistem, penjelasan, dan tombol akses utama.

Mudah dihosting

Karena hanya berupa file statis HTML, halaman ini cocok dipasang di GitHub Pages tanpa server tambahan.

Tetap sederhana

Semua pengumpulan data tetap berlangsung di Google Form sehingga alur yang sudah Anda bangun tidak perlu diubah.
