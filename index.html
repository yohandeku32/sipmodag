Mengapa SIPMODAG Dibuat?

Kami memahami birokrasi pengarsipan seringkali memakan waktu. Kami mengubah proses manual menjadi sepenuhnya otomatis.

Cara Lama

  • • Kirim file via WhatsApp atau Email
  • • Nama file tidak seragam / berantakan
  • • Admin P3AP2KB harus mengunduh satu-satu
  • • Sulit melacak OPD mana yang belum setor
Solusi!

Dengan SIPMODAG

  • • Unggah mandiri via Google Form terpusat
  • • File otomatis di-rename sesuai standar
  • • Otomatis masuk ke Folder Drive OPD terkait
  • • Dashboard Real-Time di Google Sheets

Cara Sistem Bekerja

1. Isi Form

Pilih nama instansi Anda dari dropdown, lalu unggah dokumen yang diminta via form tanpa perlu proses login tambahan.

2. Auto-Routing

Secara magis, skrip kami akan mengganti nama file Anda dan memindahkannya ke folder khusus instansi Anda di Google Drive.

3. Sinkronisasi Data

Setiap entri yang berhasil akan langsung memperbarui status pelaporan di Dashboard Google Sheets pusat P3AP2KB.

Pertanyaan Umum

Apakah saya perlu membuat akun?

Tidak. Anda hanya memerlukan akun Google (Gmail) standar untuk mengakses Google Form dan mengunggah dokumen Anda.

Bagaimana jika saya salah upload file?

Anda dapat mengisi form kembali dan mengunggah file yang benar. Sistem akan merekam *timestamp* terbaru sebagai data yang paling valid.

Format file apa yang diterima?

Kami merekomendasikan format PDF agar isi dokumen tidak berubah. Namun sistem juga menerima format dokumen seperti .doc, .docx, dan .xls.

Bagaimana saya melihat dashboard?

Link *Live Dashboard* Google Sheets dipegang secara eksklusif oleh tim penilai dari Dinas P3AP2KB untuk menjaga kerahasiaan antar OPD.

Mulai Pengarsipan

Akses form pengumpulan dokumen sekarang. Cepat, aman, dan terintegrasi otomatis dengan Google Workspace Pemerintah.
